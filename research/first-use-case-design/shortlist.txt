Seven decisions, each recommended. Drawing: DOM cells with a transform-moved playhead overlay plus canvas layers, over canvas-for-everything or SVG — cost separates none for the real workload, but DOM gives hit-testing, focus and a calibratable worst case; Preact+htm vendored (Lit equal); bespoke widgets. Serving: one co-located Starlette-on-uvicorn unit holding the browser's socket, over the same service elsewhere or in-app adapters behind a proxy, because every cross-cutting concern is then written once; port 8090 proposed. Protocols: one JSON WebSocket per page over SSE-plus-fetch or an added WebRTC channel (one total order, a quarter of fetch's cost); one per-app adapter module dialling the service, over an embedded server or TCP lines. Contract: a typed control tree over Thing Description or OSCQuery verbatim, the only schema covering a grid cell and when a write lands. Grid: a StepGrid helper in composition.data over a plain dict or a new tweaks verb; sparse cell maps carrying velocity; loop-order last-writer-wins; a per-cycle cycle event; ring over optimistic face — but only if a grid set wakes the loop promptly (recommended, p99 0.36-0.49 ms at a human tap rate) not at the next hook, which puts the face up to one beat behind the finger. Gestures: hold-and-choose-a-level over held-cell-as-modifier or in-cell zones. Host: a Pi 5 kiosk over Windows Assigned Access or a laptop, conditional on a frame-time check. Latency: 256 frames for pads over 128 or deferring.
